# Prison-Escape
It is a terminal game written in cpp
You will explore other things in it
# Explanation 
You will have 2 levels to play in it 
# First level
In first level, you need to get the right passcode you will have three attempts to do it if you fail you are out but if you guess it you will be at level two
# Second level
In Second level, you need go to the right door their are three doors two doors lead to ... 
the other one lead lead to the escape
# How to Play
You can basically play it just by double clicking the .exe file but if you are on other device then windows you will either need a cpp compiler(not recommended) it will be too much complicated so you should use online compiler like https://www.programiz.com/cpp-programming/online-compiler/ this one you will just need use GitHub clone or download zip then unzip it now you need to open the file with .cpp extension and then simply copy the code and paste it on the online compiler https://www.programiz.com/cpp-programming/online-compiler/
Then press run and it will start
